# Pickcat 消息通知助手 · 安装说明（v2.4.0）

一个浏览器扩展。**关掉 Pickcat 网页后，它会在后台继续查未读消息，有新消息就弹系统通知，写清是谁、做了什么、哪条内容，点一下直达帖子或楼层。**

主推 Chrome / Edge（Chromium 内核）。作者：羽Yu。

---

## 一、安装

1. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions/`
   - Edge：地址栏输入 `edge://extensions/`
2. 打开 **开发者模式**（Chrome 在右上角，Edge 在左下角）。
3. 点 **加载已解压的扩展程序**，选中 `pickcat-notify` 这个**文件夹**（不是里面的文件）。
4. 装好后会自动弹出**引导页**（只弹一次），并收到**一次**测试通知。之后只在真的有新消息时提醒。

> 已经装过旧版的：覆盖源码后在扩展卡片上点**刷新**，版本会变成 2.4.0，设置和已读记录都保留。

---

## 二、先登录

1. 在浏览器里打开 <https://pickcat.dao3.fun/> 并登录；
2. 在引导页或弹窗里点 **立即检查**；
3. 能读到数字 = 通了；读不到会直接写明原因（未登录 / 网络不通 / 限流）。

---

## 三、界面

**① 工具栏弹窗**（336px）
顶部未读总数 + 连接状态 + 分类计数（回复 / @我 / 赞 / 关注），中间分类切换后逐条列出「谁 + 动作 + 内容」，每条带箭头可点，底部「全部已读」、多久查一次、立即检查、更多设置。

**② 引导页**（装完自动弹一次）
四步上手 + v2.4.0 更新要点 + 能力边界（含手机端不支持）。

**③ 设置页**（弹窗里点「更多设置」）

| 设置项 | 说明 |
| --- | --- |
| 总开关 | 关掉即停止一切检查 |
| 多久查一次 | 1 / 2 / 5 分钟 |
| 检查方式 | **智能（推荐）**：先直连接口，失败再用后台页面；**只直连**：不开页面，最省资源；**只用后台页面**：最稳 |
| 桌面通知 / 图标角标 / 提示音 | 分别开关 |
| 提醒范围 | **回复、@我、赞、关注与系统** 四类分别开关，另有「合并点赞」 |
| 免打扰时段 | 例如 22:30–07:00 不弹通知，角标照常统计 |
| 后台体检 | 显示版本、定时任务、最近检查、读取方式、错误原因 |
| 兼容性表 | 各浏览器实测状态，如实标注 |
| 全部标为已读 | 手动发一次 `PATCH`（见第七节） |

> 三个页面都**跟随系统的深浅色**，下拉框全部自绘，不出现浏览器原生控件。

## 四、通知长什么样

按站点真实的 14 种通知类型写文案，不再是笼统的「有新动态」：

| 站点类型 | 文案 |
| --- | --- |
| `POST_LIKED` | 赞了你的内容 |
| `WORK_LIKED` | 赞了你的作品 |
| `REPLY_CREATED` | 回复了你的帖子 |
| `WORK_COMMENT_CREATED` | 评论了你的作品 |
| `USER_MENTIONED` | 在帖子里 @了你 |
| `USER_FOLLOWED` | 关注了你 |
| `TOPIC_EVENT` | 你关注的帖子有新动态 |
| `LEVEL_CERTIFICATION` | 等级认证有结果了 |
| `MANAGEMENT_ACTION` | 社区管理操作（14 种动作细分） |
| … | 其余见 `background.js` 的 `TYPE_INFO` |

**单条**：标题是「谁 + 做了什么」，正文是内容标题。
**多条**：标题给总数，正文按条列出，最多三条，多出来写「还有 N 条」。
**点赞合并**：同一条内容被多人赞，合成一行。

## 五、点通知会去哪

| 类型 | 落点 |
| --- | --- |
| 作品相关 | `/works/<作品ID>`，评论类再加 `#post-<楼层>` |
| 帖子相关 | `/forum/post/<帖子ID>`，楼层大于 1 时加 `#post-<楼层>` |

规则与站点前端自己的跳转函数一致。已开着同一地址的标签页时直接切过去。

## 六、关掉网页 / 关掉浏览器，到底能不能收到

| 情况 | 能不能收到 |
| --- | --- |
| 关掉 Pickcat 标签页 | **能**，定时检查跑在浏览器后台 |
| 关窗口但进程还在后台 | **能**，需在 Chrome 设置里打开「关闭浏览器后继续运行后台应用」 |
| 完全退出浏览器 / 关机 | **不能** |
| 免打扰时段内 | 不弹通知，角标照常更新 |

设置页底部有 **「关掉所有 Pickcat 页面后测试」**：真的关掉所有 Pickcat 页面，立刻检查一次并写出结果。

## 七、它是怎么拿到消息的

- 未读数：`GET /api/v1/notification-summary` → `unreadCount`、`unreadCountByType`
- 通知列表：`GET /api/v1/notifications?limit=N&type=...` → `items[]`
- 头像：`details.actor.avatar.url`（对象字段，旧版直接转字符串才坏成 `[object Object]`）
- 登录状态走 Cookie，插件**不保存密码**
- 检查由 `chrome.alarms` 驱动，不依赖任何网页是否打开
- 用 `seen` 去重，首次安装不补弹历史消息（只提醒 6 小时内的新消息）

**唯一的写请求**：你手动点「全部已读」时，会发一次 `PATCH /api/v1/notifications`（`{"read":true}`）。不点就不发。

## 八、权限说明（装的时候 Chrome 会列出这些）

| 权限 | Chrome 显示的名字 | 实际用途 | 边界 |
| --- | --- | --- | --- |
| `alarms` | 与您无关的提醒/定时器 | 定时醒一次去查未读数 | 只有插件自己的闹钟 |
| `notifications` | 显示通知 | 有新消息时弹系统通知 | 只弹自己创建的通知 |
| `storage` | 存储数据 | 存设置、上次读数、最近通知地址 | 本地，不上传 |
| `host_permissions` | 读取和更改您在 pickcat.dao3.fun 上的数据 | 调接口、必要时开后台标签页 | **只限这一个域名** |

不申请 `tabs`（「读取您的浏览记录」提示来自它，已去掉，功能不受影响）。

## 十、已知限制

1. **窗口不能放到屏幕外**：浏览器限制窗口至少一半在屏幕内，所以改用后台标签页。
2. **后台标签页会被关**：下一次检查会自动再开一个。
3. **间隔最快 1 分钟**（浏览器定时任务下限）。
4. **系统睡眠期间不检查**，唤醒后恢复。

---

## 十一、排错

| 现象 | 处理 |
| --- | --- |
| 「未登录」 | 先在浏览器里登录 pickcat；仍不行把检查方式改成「只用后台页面」 |
| 测试通知没动静 | Windows 设置 → 系统 → 通知 → 允许 Chrome/Edge 通知 |
| 后台体检显示「没注册」 | 弹窗顶部总开关被关掉了 |
| 一直「网络不通」 | 检查网络 / 代理，或站点临时故障 |
| 版本还是旧的 | 到扩展页点「刷新」重新加载 |
