# Pickcat 消息通知助手 · 安装说明（V2.4.4 beta）

一个浏览器扩展。**关掉 Pickcat 网页后，它会在后台继续帮你查未读消息，有新消息就弹系统通知，并写清是谁、做了什么、哪条内容。**

支持 Chrome、Edge 等 Chromium 内核浏览器。作者：羽Yu。

---

## 一、安装

1. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions/`
   - Edge：地址栏输入 `edge://extensions/`
2. 打开 **开发者模式**（Chrome 在右上角，Edge 在左下角）。
3. 点 **加载已解压的扩展程序**，选中 `pickcat-notify` 这个**文件夹**（不是里面的文件）。
4. 装好后会自动弹出一个**引导页窗口**，同时收到**一次**测试通知。之后就只在真的有新消息时提醒。

> 已经装过旧版的：在扩展卡片上点**刷新**（重新加载），新界面就生效了。

---

## 二、先登录

插件读的是你自己账号的未读消息：

1. 在浏览器里打开 <https://pickcat.dao3.fun/> 并登录；
2. 在引导页或弹窗里点 **立即检查**；
3. 能读到数字 = 通了；读不到会直接写明原因（未登录 / 网络不通 / 限流）。

---

## 三、界面（三块）

**① 工具栏弹窗** —— 打开就能看懂：
未读数、状态标签（已连接 / 未登录 / 已关闭）、上次检查与间隔、**最新动态**（条数同「通知里最多列几条」，1～5 条；每条含发送者头像、昵称、分类标签、所属帖子标题、楼号和时间；有帖子标识的动态整行可点直达）、多久查一次、立即检查、更多设置。（测试通知不在弹窗里，挪到了设置页底部的小链接）

**② 引导页**（装完自动弹出一次）
01 先登录 → 02 点一次立即检查 → 03 之后网页可以关掉；下方是实时状态和能力边界。

**③ 设置页**（弹窗里点「更多设置」）
检查间隔、检查方式、提醒开关、免打扰、**后台体检**、**关页验证**。

| 设置项 | 说明 |
| --- | --- |
| 多久查一次 | 六档横排：**30 秒 / 1 / 3 / 5 / 10 分钟 / 半小时**。30 秒靠内部计时器真跑 30 秒，浏览器闹钟最细 1 分钟，只当兜底 |
| 检查方式 | 默认 **智能**：你开着 Pickcat 页面就直接读它；没开就直连接口（一个页面都不开）；直连还读不到才建一个最小化的后台页兜底；兜底也失败就报错说明原因。点「其他方式…」弹出小面板，三种方式可**自己勾、按勾选先后排顺序**（勾几个就按 1、2、3 依次试，前一步不成才走下一步）；**三个全勾就等于智能** |
| 桌面通知 | 总开关（滑块）。关掉后下面这些设置会整块变灰、点不动；弹通知、提示音、角标一律停，后台检查照常跑（站内未读数字仍然会更新） |
| 通知里最多列几条 | 1 / 2 / 3 / 4 / 5 条。多了只列最近的，其余写成「还有 N 条」 |
| 图标上显示未读数 | 开关；图标角上红色数字 |
| 通知带提示音 | 开关；关掉就静默弹窗 |
| 哪些消息要弹通知 | 四类打勾开关，名字和站点一致：**提到我的（@）** / **回复我的** / **收到的赞** / **系统通知**（关注、管理通知、等级认证、申诉结果、关注帖动态）。勾掉哪类，那类就不弹 |
| 免打扰时段 | 开关 + 起止时间 |
| 通知里最多列几条 | 1 / 2 / 3 / 4 / 5 条，超出的写「还有 N 条」 |
| 免打扰时段 | 例如 22:30–07:00 不弹通知（未读照常统计，不补弹） |

> 三个页面都**跟随系统的深浅色**：Windows 用深色主题，界面自动变深色，不用手动切。下拉框全部换成自绘的分段控件，不出现浏览器原生控件。

## 四、通知长什么样

**只有一条新消息时**——标题就是谁做了什么，正文是所属帖子和楼号；点这条通知直达对应帖子并定位到那条评论：

```
starry 赞了你的帖子
《GPT，大肥鱼全天Bot？！》 · 第 12 楼
```

**多条新消息时**——标题给总数，正文按条列出（最多三条，多出来的写「还有 N 条」）：

```
Pickcat · 3 条新消息
· starry 赞了你的帖子：《GPT，大肥鱼全天Bot？！》 · 第 12 楼
· 活泼的达达蟹 回复了你的帖子：《这破站怎么还能收到消息》 · 第 24 楼
· 鲨 关注了你
```

支持的动静都会翻译成中文：赞了你、关注了你、回复了你的评论、回复了你的帖子、在帖子里 @了你、你关注的帖子有新动态、等级认证出结果了、下架申诉有结果了。

## 五、关掉网页 / 关掉浏览器，到底能不能收到

| 情况 | 能不能收到 |
| --- | --- |
| 关掉 Pickcat 标签页 | **能**。定时检查跑在浏览器后台，不依赖网页 |
| 关掉浏览器窗口、但进程还在后台运行 | **能**。前提是 Chrome 设置里打开「关闭浏览器后继续运行后台应用」 |
| 完全退出浏览器 / 关机 | **不能**。浏览器进程不在了，插件随之停止 |

设置页底部有 **「关掉所有 Pickcat 页面后测试」** 按钮：会真的关掉所有 Pickcat 页面，然后立刻检查一次并写出结果。

## 六、它是怎么拿到消息的

- 未读数：`GET /api/v1/notification-summary` → `unreadCount`
- 消息列表：`GET /api/v1/notifications?limit=5` → `items[]`（类型、发送者昵称与头像、所属帖子标题、楼号、已读状态）
- 全部已读：`PATCH /api/v1/notifications` + `{ "read": true }`——**只有你手动点弹窗里的「全部已读」才会发**，平时绝不写数据。
- 登录状态走 Cookie（和网页本身一样），插件**不保存密码**。
- 检查由浏览器定时任务（`chrome.alarms`）+ 30 秒计时器驱动，不依赖任何网页是否打开。
- 只有「未读数比上次多」且「有你开着的那几类消息」才弹通知。
- 通知文案固定是「**谁 + 做了什么 + 什么内容**」，例如「编程猫子涵awa 赞了你的帖子 / 内容：……」；类型名和站点自己的四个分类对齐（提到我的、回复我的、收到的赞、系统通知）。

## 七、权限说明（装的时候 Chrome 会列出这些）

| 权限 | Chrome 显示的名字 | 实际用途 | 边界 |
| --- | --- | --- | --- |
| `alarms` | 与你无关的提醒/定时器 | 每分钟醒一次去查未读数 | 只有插件自己的闹钟，不碰系统计划任务 |
| `notifications` | 显示通知 | 有新消息时弹系统通知 | 只弹自己创建的通知 |
| `storage` | 存储数据 | 存你的设置、上次读数、最近三条动态 | 存在浏览器本地，不上传 |
| `host_permissions` | 读取和更改您在 pickcat.dao3.fun 上的数据 | 调 `/api/v1/notification-summary` 等接口；直连读不到时才建一个最小化兜底页 | **只限 pickcat.dao3.fun 这一个域名**，其他网站一律无权 |

**关于「读取您的浏览记录」**：这个提示原本来自 `tabs` 权限。2.1 版已经把它去掉了——实测在只有站点级权限的情况下，插件依然能找出你开着的 Pickcat 页面、也能管理兜底页，而其他网页的地址、标题一律读不到（实测返回 `url: null`）。

插件**不读**：你的密码、其他网站的浏览记录、剪贴板、文件系统；**不写**：不发帖、不评论、不点赞、不改任何内容——所有请求都是 `GET`，**唯一例外是你手动点「全部已读」时的一条 `PATCH`**。

## 八、已知限制（实测出来的）

1. **窗口不能放到屏幕外。** Chrome/Edge 会报 `Bounds must be at least 50% within visible screen space`，所以不能靠「屏幕外小窗口」藏起来。
2. **默认的读取顺序**：先找你已开着的 Pickcat 页面 → 没有再直连接口 → 直连也读不到才建兜底后台页。只要你自己开着页面，它就只读那个页面，**不会在标签栏里另开一个标签**。想改顺序就用「其他方式…」自己勾，勾几个就按勾的先后依次试。
3. **兜底后台页是最小化的独立小窗**：不进标签栏、不抢焦点，页面加载完会连压三次最小化。它只有在你「一个 Pickcat 页面都没开、直连又读不到」时才会被建一次，之后一直复用。
4. **兜底页会被关闭。** 你手动关掉它，下次真的读不到时才会再建一个。
5. **间隔最快 30 秒。** 30 秒这档用内部计时器（`setTimeout` 链）真跑；浏览器的定时闹钟最细 1 分钟，只当「进程被挂起时唤醒」的兜底，所以体检里的「定时任务」一行会写成「每 30 秒（计时器执行，闹钟 1 分钟兜底）」。
6. **系统睡眠期间不检查**，唤醒后恢复。
7. **桌面通知只有一个图标位**：Chrome 系统通知不能在文字旁边再塞一张独立头像小图。单条新消息时，通知图标直接用发送者头像；多条消息或对方没头像时，回退扩展自带图标。另外站点接口不返回回复正文，通知里只能给出所属帖子标题和楼号；点开是直达帖子线程并通过 `#post-<评论id>` 锚点定位到那条评论，若目标评论还没被懒加载出来，就停在帖子顶部。
8. **头像走后台中转**：站点头像接口带跨源限制（`cross-origin-resource-policy: same-origin`），扩展弹窗页面不能直接 `<img>` 拉取；扩展由后台把头像抓成 data URL 再显示到弹窗和通知图标里，抓不到时退回昵称首字母圆形占位。

## 九、排错

| 现象 | 处理 |
| --- | --- |
| 「未登录」 | 先在浏览器里登录 pickcat；或者干脆开着 Pickcat 页面（智能模式会直接读那个页面） |
| 测试通知没动静 | Windows 设置 → 系统 → 通知 → 允许 Chrome/Edge 通知 |
| 后台体检显示「没注册」 | 弹窗顶部总开关被关掉了，打开即可 |
| 一直「网络不通」 | 检查网络 / 代理，或站点临时故障 |
