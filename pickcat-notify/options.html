后台体检

关掉网页还能收到吗
关掉 Pickcat 标签页：能。检查跑在浏览器自己的定时任务里，跟网页开没开无关。
关掉浏览器窗口、进程还在后台：能。需要在浏览器设置里打开「关闭浏览器后继续运行后台应用」。
完全退出浏览器：不能。浏览器进程没了，插件也停。
兼容性
这一版按桌面 Chromium 内核写成，接口全部做了回调 / Promise 双兼容。建议直接用 Chrome 或 Edge，不折腾 360、QQ 这类加壳浏览器。
环境能不能用
Windows · Chrome（推荐）/ Edge支持（已真机实测）
macOS · Chrome / Edge支持（同一套代码，没有平台专属接口）
Linux · Chrome / Edge支持（同上）
其它 Chromium 内核（Brave / Vivaldi / Opera）一般可用，未逐个实测
华为浏览器不能装扩展（内核是 Chromium，但华为没开放扩展入口）
Firefox 桌面暂不支持（后台机制不同，需要单独适配）
手机 / 平板浏览器、鸿蒙 NEXT不能装扩展
手机端做不到，是浏览器不允许装扩展，不是这个插件偷懒；短期内没有可靠替代方案。
排错
未登录：先在浏览器里登录 Pickcat，再点立即检查；仍不行就把检查方式改成「只用后台页面」。
没有通知：检查 Windows 设置 → 系统 → 通知，允许 Chrome / Edge 弹出通知。
后台体检显示「没注册」：弹窗顶部总开关被关掉了，打开即可。
一直网络不通：检查网络或站点是否临时故障。
